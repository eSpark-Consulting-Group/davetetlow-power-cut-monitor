# Power Cut Monitor
#### Client Name: Dave Tetlow

## Project Requirements
Below are the core features needed from the product:
- The device must be able to passively monitor the power flow to a refrigerator without disrupting normal wiring of the refrigerator.
- The device must be powered via a replaceable battery of suitable size that can provide good backup before requiring replacement.
- The device must report below information to cloud:
    - The power cut to the refrigerator.
    - Battery value (only to be reported when battery goes below 20%)
- The device form factor should be smallest possible.
- The device should be very power efficient.
- The device should have a toggle switch to allow user to turn Power ON/OFF.
